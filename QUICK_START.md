# 🚀 QUICK START GUIDE - 5 Minutes to Full Setup

## Step 1: Initialize Database (1 minute)

Open your browser and visit:
```
http://localhost/setup_verify.php
```
(Replace `localhost` with your domain)

**What it does:**
- ✓ Creates all necessary database tables
- ✓ Verifies all files are in place
- ✓ Checks all connections
- ✓ Shows you the setup status

**Expected Result:** Shows green checkmarks for all items (100% complete)

---

## Step 2: Test Fisherfolk Homepage (2 minutes)

1. Go to login page: `http://localhost/login.php`
2. Click "User Portal" tab
3. Login with any fisherfolk user (example: username `juan`)
4. You'll be redirected to the **new homepage** ✨

**What you'll see:**
- Left sidebar with navigation
- Community feed in the center
- Announcements on the right
- "Share Your Views" post box

---

## Step 3: Test Dark Mode (1 minute)

On the homepage:
1. Look for the **🌙 Dark Mode** button in the left sidebar (bottom)
2. Click it
3. The entire page turns dark ✨
4. Click again to return to light mode
5. Refresh the page - your preference is saved!

## 🎨 Try Changing a Color (Admin)

1. As admin, click **🎨 Theme Colors** in sidebar
2. Find "Sidebar Color" card
3. Click the color picker circle
4. Choose blue color (#2196F3)
5. Watch the preview update live
6. Click "Save Changes" button
7. Go back to admin dashboard
8. Notice the sidebar is now blue! ✨

---

## 📊 Check Activity Logs (Admin)

1. As admin, click **📋 Activity Logs** in sidebar
2. You'll see a table of all recent activities:
   - Who: User that performed action
   - What: Action performed
   - When: Timestamp
   - Where: Which table

3. Use pagination buttons to see more logs

---

## 💬 Create a Post (Fisherfolk)

1. Go to homepage as any fisherfolk user
2. In the "Share Your Views" box, type something:
   - Example: "The fishing season was great this year!"
3. Click the **"Post"** button
4. Your post appears in the feed below!
5. Click the **Activity Logs** as admin to see this tracked
